Accessibility

Baseline expectations
  • Skip link to main content on every page
  • Visible :focus-visible rings on interactive controls
  • Logo and decorative motion honor prefers-reduced-motion
  • Tables announce title, description, and column structure for assistive tech
  • Color is never the only status cue — pair with labels

Herman is maintained as a living mirror of hermanlex.com. Tokens and components stay aligned with production CSS.
